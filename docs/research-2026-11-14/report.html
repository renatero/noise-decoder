Free social media and news aggregation: what is usable, and under what conditions

There is no verified, lawful, completely free API covering every requested social platform. Build a unified application over open social APIs, publisher feeds and institutional datasets, then add approval-gated platforms individually. A common JSON interface is achievable; universal free access is not.

This report contains 60 comparison entries, a live GitHub maintenance audit, two ranked top-ten lists, platform recommendations, an implementation architecture, cost estimates and runnable examples. All availability/pricing checks are dated 2026-11-14. “Verified” means documentation or repository checked on that date, not that an authenticated account, commercial license or production entitlement was obtained.

Recommendation for Noise Decoder

Keep Noise Decoder as the unified interface, use Miniflux for feed ingestion, and add direct platform connectors. Start with publisher RSS, Hacker News, Bluesky, Mastodon, GDELT metadata/bulk, Federal Register, USGS and approved ReliefWeb access. Add Lemmy, PeerTube, Nostr and Wikimedia where their communities fit the topics being monitored. Miniflux provides a straightforward JSON API; it does not grant access to closed platforms.

Best ready-made multi-platform prototype: Harken. Its repository offers a lightweight local listening interface with HN/Bluesky and optional sources. Inspection found OAuth Reddit access and an official X connector, which is preferable for this objective but does not remove approval or payment requirements. Treat it as a candidate to evaluate, not an audited production replacement.

Best broad news combination: native RSS + GDELT + Media Cloud. RSS provides publisher-selected updates, GDELT expands discovery, and Media Cloud supports research/history. These overlap; deduplicate by canonical article URL and preserve the originating publisher rather than counting every aggregator copy as independent evidence. GDELT datasets; Media Cloud API.

Research findings that change implementation choices: X read access is paid; Reddit is approval-gated; Meta’s research API cannot export raw data to this app; Telegram’s content terms restrict AI aggregation; Discord bans mining/scraping and resale of API data. Free software or public visibility does not override these restrictions. X pricing, Reddit access, Meta research access, Telegram licensing, Discord policy.

NewsAPI Developer is excluded from the recommended deployed stack because it is development/testing only. Apify’s recurring $5 credit pays for limited automation; it is not a license to scrape social platforms.

Practical capacity: at 100 requests/day, one query can run roughly every 15 minutes with little spare capacity; ten queries can each run only about ten times/day. At three articles/request, 100 requests can return at most 300 article slots/day before duplicates. A free tier’s headline request count can therefore be misleading for continuous multi-topic monitoring. Threads’ allowance is user-wide across applications. Search-page pagination also consumes quota.

OpenMagpie was investigated but is not the preferred lawful API foundation. Its current X connector uses Twikit, YouTube uses yt-dlp, and Reddit uses anonymous RSS. These are materially different from approved official API access. Its license also has an enterprise-directory exception; the GitHub API reported NOASSERTION rather than a clean SPDX match.

Federated search is still partial. Mastodon, Lemmy and PeerTube queries generally cover what a chosen server has indexed or received. Nostr searches cover selected relays, and optional full-text support differs. SearXNG aggregates search engines but does not create missing social API permissions. The application should expose coverage and freshness rather than imply that a zero-result query searched the entire Internet.

Commercial listening services are not free substitutes. Brand24 offers a 14-day trial, not a recurring free listening entitlement. Mention’s pricing did not establish a usable recurring free API entitlement in this review. Do not turn an account trial or demo into a “free API” recommendation. Brave’s conditional monthly credits also fail the no-card preference under its checked onboarding requirements.

Maintenance evidence and project caveats

GitHub metadata was fetched directly from the GitHub API, including last-push timestamps and archived flags. A recent push is a useful maintenance signal, not proof of reliable connectors, security or production readiness. GitHub-detected licenses need confirmation against LICENSE files before adoption. BSL-1.0 for TDLib means the Boost Software License, not the similarly abbreviated Business Source License.

  • Telethon’s GitHub repository is archived because the project moved to Codeberg; do not conclude that the entire project is abandoned.
  • Nitter and Twint were archived at verification time. snscrape had no push since 2023. None is a reliable substitute for sanctioned X access.
  • HN Search’s source repository is archived while its hosted search endpoint still responded in the live test. Keep the official HN API as a separate dependency.
  • Freed and NewPipeExtractor were discovered, but browser capture/extraction is not equivalent to a licensed server-side social API.
  • Current RSSHub metadata reports AGPL-3.0; do not rely on older license descriptions. The old Bluesky Jetstream implementation lives in a legacy repository; use current documentation for new integrations.

F. Recommended technology stack

For this project, start with Python/FastAPI, PostgreSQL, Miniflux and a small scheduled worker. Keep the existing source registry and add adapters behind a common contract. Use httpx for REST, feedparser for direct XML feeds, and a current Jetstream client for streaming. Add a queue when retry volume or traffic justifies it. Use PostgreSQL full-text/trigram indexes first; add OpenSearch only when search volume or language needs justify another service. These are architecture recommendations, not measured capacity guarantees.

A normalized record should retain source, source_id, source_url, author/account identifier when permitted, title/text as allowed, published_at, observed_at, collected_at, language, tags/entities, source-scoped metrics, reply/parent IDs, content/license provenance, deletion status and refresh deadline. Keep raw source timestamps: an aggregator’s “seen” time is not necessarily publication time.

Deduplicate first by source-native ID, then canonical article URL, then a content fingerprint. Preserve reposts and cross-post relationships rather than erasing useful coordination signals. Trend scores should compare each source against its own normal activity; a Reddit vote, a Mastodon boost and a YouTube view are not interchangeable observations.

Suggested collection policy: use conditional HTTP requests for feeds; start with 5–15-minute feed refresh intervals adjusted to publisher rules; use streams for low-latency open-network events; serialize GDELT DOC requests and stop on sustained 429s; checkpoint after successful commits; honor Retry-After; never rotate identities to defeat quotas. Distinguish “no matches” from “source unavailable” in the dashboard.

Storage and redistribution: adopt an explicit per-source policy rather than a global “public data” flag. API permission, software license and content copyright are different things. Store links/provenance and the permitted metadata/content, propagate removals, enforce refresh/deletion deadlines, and gate exports by source. YouTube has refresh/deletion requirements and a separate approved derived-metrics regime. Telegram and Discord are especially unsuitable for an unrestricted AI archive under the policies cited above. This report identifies published restrictions; it does not establish a bespoke redistribution license.

Implementation sequence: first add native feeds and government signals, then GDELT bulk/limited search and Mastodon; validate Bluesky search access and stream handling; request Threads/ReliefWeb/Media Cloud access where useful; evaluate YouTube’s permitted use and quota fit; keep restricted platforms disabled until the required approval is in place. This research adds documents and examples only; it does not enable new collectors or alter the deployed service.

Practical integration examples

The Python example uses only the standard library, fetches one page each from HN search and Federal Register, and emits normalized JSON lines. Optional Bluesky/GDELT paths report access failures rather than silently pretending an empty result is successful coverage.

"""Small, read-only API examples; Python 3.10+, standard library only.

Run: python3 integration_examples.py --query climate --limit 3
Optional: --source bluesky --source gdelt (access/throttling may prevent results).
One page per source, no background service, storage, article fetching or deployment.
This demonstrates normalization, NOT complete collection or redistribution permission.
"""
import argparse
from datetime import datetime, timezone
import json
import sys
from urllib.error import HTTPError
from urllib.parse import urlencode
from urllib.request import Request, urlopen

MAX_BYTES = 2_000_000


def get_json(url, params):
    request = Request(url + '?' + urlencode(params), headers={
        'User-Agent': 'NoiseDecoder-ResearchExample/1.0',
        'Accept': 'application/json',
    })
    with urlopen(request, timeout=25) as response:
        body = response.read(MAX_BYTES + 1)
        if len(body) > MAX_BYTES:
            raise ValueError('Response exceeds example body limit')
        return json.loads(body)


def normalize(source, identifier, url, title, published_at=None, observed_at=None):
    return {
        'id': f'{source}:{identifier}',
        'source': source,
        'source_id': str(identifier),
        'url': url,
        'title': title,
        'published_at': published_at,
        'observed_at': observed_at,
        'collected_at': datetime.now(timezone.utc).isoformat(),
        'rights_status': 'source-specific; not cleared for unrestricted redistribution',
    }


def fetch(source, query, limit):
    if source == 'hn':
        data = get_json('https://hn.algolia.com/api/v1/search_by_date', {
            'query': query, 'tags': 'story', 'hitsPerPage': limit, 'page': 0,
        })
        return [normalize('hn', x['objectID'],
                          'https://news.ycombinator.com/item?id=' + x['objectID'],
                          x.get('title'), x.get('created_at')) for x in data['hits']]
    if source == 'federal-register':
        data = get_json('https://www.federalregister.gov/api/v1/documents.json', {
            'conditions[term]': query, 'per_page': limit, 'order': 'newest',
        })
        return [normalize(source, x['document_number'], x.get('html_url'),
                          x.get('title'), x.get('publication_date')) for x in data['results']]
    if source == 'gdelt':
        data = get_json('https://api.gdeltproject.org/api/v2/doc/doc', {
            'query': query, 'mode': 'artlist', 'format': 'json',
            'maxrecords': limit, 'timespan': '24h',
        })
        # seendate is observation time; do not present it as publisher publication time.
        return [normalize(source, x['url'], x['url'], x.get('title'),
                          observed_at=x.get('seendate')) for x in data.get('articles', [])]
    if source == 'bluesky':
        data = get_json('https://public.api.bsky.app/xrpc/app.bsky.feed.searchPosts', {
            'q': query, 'limit': limit, 'sort': 'latest',
        })
        records = []
        for x in data.get('posts', []):
            did = x['author']['did']
            record_key = x['uri'].rsplit('/', 1)[-1]
            records.append(normalize(source, x['uri'],
                                     f'https://bsky.app/profile/{did}/post/{record_key}',
                                     x['record'].get('text'), x['record'].get('createdAt'),
                                     x.get('indexedAt')))
        return records
    raise ValueError('Unsupported source')


def main():
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument('--query', default='climate')
    parser.add_argument('--limit', type=int, default=3)
    parser.add_argument('--source', action='append', choices=['hn','federal-register','gdelt','bluesky'])
    args = parser.parse_args()
    if not 1 <= args.limit <= 20:
        parser.error('--limit must be between 1 and 20')
    failed = False
    for source in dict.fromkeys(args.source or ['hn', 'federal-register']):
        try:
            records = fetch(source, args.query, args.limit)
            for record in records:
                print(json.dumps(record, ensure_ascii=False))
            print(json.dumps({'source': source, 'status': 'ok', 'records': len(records),
                              'coverage': 'one page only'}), file=sys.stderr)
        except HTTPError as exc:
            failed = True
            print(json.dumps({'source': source, 'status': exc.code,
                              'retry_after': exc.headers.get('Retry-After'),
                              'action': 'Stop; review access or retry later under provider limits'}),
                  file=sys.stderr)
        except (OSError, ValueError, KeyError) as exc:
            failed = True
            print(json.dumps({'source': source, 'status': 'error', 'detail': str(exc)}), file=sys.stderr)
    return 1 if failed else 0


if __name__ == '__main__':
    raise SystemExit(main())
